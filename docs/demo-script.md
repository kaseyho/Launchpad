# LaunchPad demo script

Target recording length: 2 minutes 20 seconds or less.

## Human + WebMCP sequence

**0:00–0:20 — One shared launch line**

“Product teams have plenty of signals but very little defensible lineage. LaunchPad turns scattered evidence into an idea you can defend. This factory is not decoration: each station reflects the real research state.”

Point to the three-step WebMCP rail: the agent reads this workspace, calls one of 16 typed tools, and the same page updates. Copy the prepared prompt and give it to the browser agent.

**0:20–0:50 — WebMCP moves the product**

Ask the agent to inspect state, load the curated problem, plan research, source the evidence pack, and extract findings. As each real tool completes, point out the live agent event in the rail and the active factory station. There is no parallel chat-only workflow: WebMCP changes the same workspace the human can operate.

Open one finding and show its exact source passage, population, timeframe, caveats, and synthetic-data label. Ask the agent to accept the evidence and synthesize insights.

**0:50–1:15 — Ideas are assembled, not improvised**

Generate three candidates and inspect the leader. Point out that Admin Guild scores 98 because every component currently has accepted support.

**1:15–1:40 — The recommendation reacts to evidence**

Say: “Remove community anecdotes and use only first-party analytics, primary research, and recent market evidence.”

The agent calls `review_findings`. Show the community evidence leave the accepted lane, Admin Guild fall to 50% support with two unsupported components, and First-Value Flightpath become the recommendation at 90.

**1:40–2:00 — Attack, then commit**

Stress-test First-Value Flightpath. Point out the counter-evidence and feasibility risks. Finalize the blueprint only after the quality gates pass.

**2:00–2:20 — Trace the proof and the agent**

Open “Why Outcome preview exists.” Follow the illuminated path from feature to insight to the worked-examples finding and its DOI source. Open **Activity** briefly to show the agent actor, exact tool, result, and workspace version, then close it and export the public-safe blueprint.

Close with: “Evidence in. Defensible ideas out. LaunchPad is one shared product for humans and agents, made operable by WebMCP.”
